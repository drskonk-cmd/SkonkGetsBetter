MON SUIVI SANTÉ — V2 PWA

Contenu :
- index.html : application
- manifest.webmanifest : paramètres d'installation PWA
- sw.js : fonctionnement hors connexion après installation

Important :
Une PWA ne peut pas être installée correctement depuis un simple fichier local (file://).
Les trois fichiers doivent être servis via HTTPS (ou localhost). Une fois hébergée en HTTPS,
ouvrez index.html avec Chrome sur le Pixel puis utilisez « Installer l'application » ou
« Ajouter à l'écran d'accueil ».

Données :
Les données de suivi sont conservées dans localStorage sur l'appareil/navigateur.
Aucun serveur applicatif n'est utilisé par ce code pour stocker les données.
Effacer les données du site/navigateur peut donc supprimer l'historique.
